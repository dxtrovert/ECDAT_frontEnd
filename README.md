# ECDAT Frontend

Enterprise Cryptographic Discovery & Assessment Tool (ECDAT) - React + TypeScript Frontend Application built for NTRO / SIH 2026.

## Features & Screens
1. **Dashboard**: Executive overview of cryptographic posture and Q-Day timeline.
2. **Scan**: Discovery engine scanner configuration and real-time telemetry.
3. **Crypto Asset Inventory**: Comprehensive register of identified cryptographic primitives.
4. **Blast Radius / Dependency Graph**: Interactive network graph showing asset reachability and risk propagation.
5. **PQC Migration**: Migration priority queue and post-quantum cryptography transition roadmap.
6. **Compliance**: Sovereign posture indexing against NTRO & India CII baselines.
7. **Drift Detection**: Posture change analysis and auditable changelog between scans.

## Tech Stack
- React 18 + TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run type check
npm run typecheck

# Run linter
npm run lint

# Build for production
npm run build
```
